# 🚅 SRT Watcher (Docker, Headful/Headless)

컨테이너가 뜨면 **즉시 실행**되어 SRT 좌석을 **조회 → 예약 → (옵션) 결제/발권**까지 자동 처리합니다.  
특정 시각 근처 열차를 안정적으로 노리고, 성공 시 **텔레그램 알림**으로 바로 확인할 수 있습니다.

---

## ✨ 핵심 장점

- **정확 타깃팅**: 목표 시각 ±허용분(`SRT_TOLERANCE_MIN`)만 클릭 대상
- **사람처럼 대기**: 3–10초 지터, 큐/네비게이션 대기 처리로 차단 위험 완화
- **복구 내성**: 로그인 만료·팝업·지연 등 발생 시 자동 복구 후 재시도
- **원클릭 결제(옵션)**: .env에 카드/인증 정보만 넣으면 결제 및 발권 완료
- **스마트폰 발권 보장**: 탭 클릭 + 폼 파라미터(`iseTpCd=1`) 검증/보정으로 홈티켓 방지
- **컨테이너형 배포**: 로컬/서버 어디든 Docker만 있으면 동일하게 동작
- **알림 자동화**: 예약/결제 성공 시 텔레그램 푸시

---

## 🧩 기능 개요

- 🔎 **좌석 탐색**: 목표 시각 근처 열차 수집 및 스코어링, 빠른 DOM 탐색  
- 🎯 **자동 예약**: “예약하기/좌석선택” 감지 즉시 클릭, 큐 진입/자동 전환 대응  
- 🧑‍🤝‍🧑 **승객 수 선택**: 드롭다운 기반 **1–9명** 안정 선택(상한 자동 클램프)  
- 💳 **자동 결제(옵션)**: 카드 4분할 번호·유효기간·비밀번호 2자리·인증번호 입력 후 “결제 및 발권”  
- 📱 **스마트폰 발권**: UI 클릭 + 숨은 필드(`iseTpCd=1`) 보정으로 발권 수단 일관성 확보  
- 📨 **알림**: 예약/결제 성공 상태 텔레그램 전송  
- 🛡️ **예외/리트라이**: 셀렉터 미스/팝업/프레임 지연 발생 시 캡쳐(HTML/PNG) 후 안전 재시작

## ⚙️ 환경 변수(.env) — 무엇이 가능해졌나

> 값을 채우면 해당 기능이 **즉시 활성화**됩니다.

### 필수 기본값
```env
# SRT 로그인 정보
SRT_USER=회원번호
SRT_PASS=비밀번호

# SRT 예약 목표 정보
SRT_ORIGIN=수서          # 한글 역명
SRT_DEST=부산           # 한글 역명
SRT_DATE=2025-12-29     # YYYY-MM-DD
SRT_TIMES=09:20,09:00   # 우선순위대로 시도 (쉼표 구분)

# 텔레그램 챗봇 토큰 정보
TG_BOT_TOKEN=123456:ABCDEF
TG_CHAT_ID=987654321
```

### 🎯 탐색/예약 정밀도
```env
SRT_TOLERANCE_MIN=5     # 목표 시각 ± 허용분(분). '클릭' 기준
SRT_PASSENGERS=2        # 승객 수(1~9, 9 초과 시 자동 9로 클램프)
SRT_SEAT_CLASS=일반실   # 일반실 | 특실
SRT_MODE=reserve        # search | reserve (search는 예약 미수행)
SRT_HEADLESS=true       # 헤드리스 모드 (Docker 내부 권장)
```

**옵션 설명**
- **`SRT_TOLERANCE_MIN`**: 목표 시각(예: `SRT_TIMES=08:05`) 기준 ±N분 범위만 실제 클릭 대상으로 인정  
  - 추천: `3~5`(정확 타게팅) / 유연: `8~10`
- **`SRT_PASSENGERS`**: 드롭다운으로 1~9명 안정 선택  
- **`SRT_SEAT_CLASS`**: `일반실`/`특실` 우선 매칭(없으면 내부 폴백 로직 따름)
- **`SRT_MODE`**: `search`(탐색·알림) / `reserve`(예약까지 자동, 결제는 옵션)
- **`SRT_HEADLESS`**: 브라우저 창 없이 백그라운드 실행

### 💳 결제/발권 자동화(옵션)
```env
PAYMENT_MODE=true               # 결제/발권 자동 수행 (true/false)
PAY_CARD_NUM=1234-1234-1234-1234
PAY_CARD_MM=12                  # 01~12 (2자리)
PAY_CARD_YY=2030                # 2025~2037 (4자리)
PAY_CARD_PW2=12                 # 카드 비밀번호 앞 2자리
PAY_ID6=900101                  # 주민번호 앞 6자리(YYMMDD)
```
- **스마트폰 발권 보장**: “스마트폰 발권” 탭 클릭 후 `iseTpCd=1` **검증/강제 세팅** → 홈티켓 방지  
- **안전장치**: 제출 직전 `iseTpCd` 검증 실패 시 중단(오발권 차단)

## 🎯 탐색/예약 정밀도 (설정 가이드)

“언제, 어떤 열차를 클릭할지”를 미세 조정하는 옵션들입니다.

```env
SRT_TOLERANCE_MIN=5     # 목표 시각 ± 허용분(분). 실제 클릭 기준
SRT_PASSENGERS=2        # 승객 수(1~9)
SRT_SEAT_CLASS=일반실   # 일반실 | 특실
SRT_MODE=reserve        # search | reserve
SRT_HEADLESS=true       # 헤드리스 모드 (Docker 내부 권장)
```

**동작 팁**
- **수집은 넓게, 클릭은 타이트하게**: 후보 열차는 넓게 मो으되, 실제 클릭은 `SRT_TOLERANCE_MIN`으로 엄격히  
- **큐/지연 대비**: 지연으로 1~2분 어긋나는 경우가 있어 `5~8`로 여유를 주면 안정적  
- **정확 타임 스나이핑**: 특정 열차가 확실하면 `3~5`로 좁혀 오클릭 최소화

**예시**
- 목표: `SRT_TIMES=08:05`, `SRT_TOLERANCE_MIN=5` → **08:00~08:10**만 클릭 대상  
- 2명, 일반실, 실제 예약까지 자동:
```env
SRT_PASSENGERS=2
SRT_SEAT_CLASS=일반실
SRT_MODE=reserve
```

## 🔁 내부 동작 흐름

1. 로그인 상태 확인 → 필요 시 재로그인  
2. 후보 열차 수집 → `SRT_TOLERANCE_MIN` 기준으로 클릭 대상 선정  
3. 예약 시도(큐 진입/자동 전환 대기 포함)  
4. (옵션) 결제 페이지 진입 → 체크박스 해제 → 카드/유효기간/비번2자리/인증번호 입력  
5. **스마트폰 발권 확정(iseTpCd=1)** → “결제 및 발권” 클릭  
6. 성공 문구 감지 → 텔레그램 알림

## 🧪 운영 팁

- **정확히 특정 시간 노릴 때**: `SRT_TOLERANCE_MIN=3~5`  
- **지연/큐 대비 여유**: `5~8`로 완화  
- **폴링 지터 유지**: 서버 감지 회피를 위해 기본 3–6초 지터 권장
- **뷰포트/프레임 지연**: 간헐 셀렉터 미스는 재시작 루프가 회복
